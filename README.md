## ✍️ Adding a Note

1. Copy [`Templates/article_note_template.md`](Templates/article_note_template.md) into `Articles/`.
2. Name the file with underscores, e.g. `Attention_Is_All_You_Need.md`.
3. Fill it in and add a row to the index above.
